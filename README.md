# ปักกิ่งของเรา · Trip 2026

เว็บแอปแผนเที่ยวปักกิ่ง 4 วัน 3 คืน ออกแบบให้ใช้ได้ทั้งมือถือและคอมพิวเตอร์

## เปิดเว็บ

GitHub Pages เผยแพร่จาก branch `main` อัตโนมัติเมื่อมีการ push โค้ด

## ข้อควรรู้เรื่องความเป็นส่วนตัว

เว็บ Pages นี้เป็นสาธารณะ ทุกคนที่มีลิงก์เปิดดูได้ และแหล่งโค้ดก็เป็นสาธารณะเช่นกัน เนื้อหาจึงไม่เหมาะกับข้อมูลที่ต้องจำกัดเฉพาะ 2 คน

เช็กลิสต์บันทึกในเบราว์เซอร์ของอุปกรณ์นั้นเท่านั้น ไม่ซิงก์ระหว่างมือถือกับคอมพิวเตอร์ ส่วน PDF ใบจอง เลขจอง ที่อยู่/เบอร์โรงแรม และรายละเอียดการชำระเงินจะไม่ถูกเผยแพร่ในเว็บนี้

ก่อนเดินทางควรตรวจเวลาเปิด จุดขึ้นรถ เทอร์มินอล และเงื่อนไขบัตรกับผู้ให้บริการอีกครั้ง
